Etapa 6: **Implantação, Containers e Deploy do Frontend**

*Etapa opcional.*

Essa etapa é opcional e apresenta um nível de complexidade maior, focando na implantação da aplicação full-stack utilizando Docker containers, além do deploy do backend e deploy do frontend. Ela é destinada a você caso deseje aprofundar os seus conhecimentos sobre a implantação em ambientes de produção, incluindo a utilização de containers para gerenciar e escalar a aplicação de maneira eficiente.

Nessa etapa, você poderá optar por utilizar a API fornecida pela instituição ou desenvolver e implantar uma API própria. Caso opte por usar a API fornecida pela instituição, o foco será exclusivamente no deploy do frontend, que precisará ser integrado à API existente. Caso prefira desenvolver sua própria API, você também será responsável pela implantação do backend, além do frontend, utilizando Docker e AWS para garantir que a aplicação esteja pronta para um ambiente de produção.

As tarefas desta etapa incluem:

1. **Preparação para o Deploy do Backend (opcional se usar API fornecida)**

   Se você escolher usar a API fornecida pela instituição, o foco será na integração do frontend com a API existente, sem a necessidade de implantar o backend. Caso opte por desenvolver sua própria API, você precisará seguir o processo de deploy do backend usando Docker containers e AWS.

2. **Deploy do Frontend**

   Realizar o deploy do frontend da aplicação, que poderá ser feito utilizando plataformas como Netlify, integrando-o corretamente com a API (seja a fornecida ou a sua própria).

3. **Uso de Docker para Containers**

   Se você estiver implantando sua API própria, será necessário containerizar tanto o backend quanto o frontend utilizando Docker. Isso garantirá que a aplicação seja facilmente gerenciável e escalável, além de facilitar a implantação e manutenção em ambientes de produção.
