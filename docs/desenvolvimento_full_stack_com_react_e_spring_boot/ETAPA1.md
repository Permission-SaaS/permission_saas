Etapa 1: **Integração do Frontend e Backend**

Você precisa integrar o backend, desenvolvido em Spring Boot, com o frontend React, estabelecendo a comunicação entre as duas partes da aplicação e garantindo a troca de dados por meio de APIs RESTful. Nessa etapa, você precisa trabalhar nas seguintes tarefas:

1. Implementar a comunicação entre o frontend e o backend utilizando chamadas às APIs RESTful.
2. Garantir que o frontend consuma corretamente os dados fornecidos pelo backend.
3. Aplicar boas práticas para integração: validação de dados e tratamento de erros nas requisições.
