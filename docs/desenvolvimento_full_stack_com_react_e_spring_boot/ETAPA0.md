Etapa 0: **Integração do Frontend e Backend**

*Preparação, antes das etapas principais. No enunciado esta etapa tem o mesmo título da etapa 1; o conteúdo é a configuração do ambiente.*

Antes de começar as etapas principais do projeto, você precisa configurar corretamente o ambiente de desenvolvimento para garantir que tanto o backend (Spring Boot) quanto o frontend (React) estejam prontos para a integração e o desenvolvimento contínuo. O objetivo desta fase é criar uma base sólida que será usada nas etapas seguintes. Para isso, você precisa realizar as seguintes tarefas:

1. Configurar o ambiente de desenvolvimento para trabalhar com Spring Boot e React.
2. Utilizar um backend simples que exponha um serviço RESTful básico.
3. Construir um frontend inicial que consuma o serviço RESTful do backend.
4. Elaborar um mockup da interface do usuário para orientar as próximas etapas do desenvolvimento.
