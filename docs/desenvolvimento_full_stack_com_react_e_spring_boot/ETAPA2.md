Etapa 2: **Criando e Consultando Dados com CRUD**

Você precisa implementar as funcionalidades de criação e consulta de dados (Create e Read) no projeto. Essas funcionalidades permitirão que o frontend se comunique com o backend para armazenar e exibir informações. Nessa etapa, você precisa trabalhar nas seguintes tarefas:

1. Analisar a funcionalidade de criação de registros no backend e integrá-la ao frontend.
2. Analisar a funcionalidade de consulta de dados no backend e exibir os dados no frontend.
