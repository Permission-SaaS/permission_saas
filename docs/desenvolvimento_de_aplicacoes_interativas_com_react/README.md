### **Uso de IAs: Sinal Amarelo 🟡**

Neste trabalho, os alunos têm permissão para usar ferramentas baseadas em IA nas seguintes tarefas: **esclarecimento de conceitos, sugestões de organização e componentização da aplicação, geração ou complementação de trechos pontuais de código, identificação e correção de erros, refatoração, criação e revisão de estilos, elaboração de dados para testes, construção e validação de formulários, integração e diagnóstico de requisições a APIs externas, sugestões de abordagens de gerenciamento de estado, Hooks, Context API, tratamento de operações assíncronas e navegação**. Todas as fontes, incluindo ferramentas de IA, devem ser devidamente citadas. O uso de IA de forma inconsistente com os parâmetros acima será considerado má conduta acadêmica e estará sujeito à aplicação do código disciplinar. Observe que os resultados da IA podem ser tendenciosos e imprecisos. É responsabilidade do aluno garantir que as informações usadas da IA sejam precisas. Aprender como usar ferramentas baseadas em IA de maneira cuidadosa e estratégica contribui para o desenvolvimento das habilidades, refinamento de seu trabalho e prepara o aluno para sua futura carreira.

Neste projeto, você será responsável por desenvolver um sistema CRUD completo (Create, Read, Update, Delete) de sua escolha, como a gestão de uma escola, academia, locadora ou outro escopo de sua preferência. Utilizando React como framework principal, você irá aplicar os conceitos apresentados em aula, desde a criação e estilização de componentes até o consumo de APIs e gerenciamento de estado. Durante o desenvolvimento, será essencial utilizar ferramentas modernas do JavaScript ES6, manipular listas e formulários, implementar navegação entre páginas com React Router, além de integrar APIs externas para aprimorar a aplicação. O objetivo é entregar um sistema funcional, organizado e que demonstre sua compreensão das tecnologias aprendidas.

### **Organização do Projeto em Features**

Neste projeto, iremos dividir o desenvolvimento em três features principais. Uma feature é uma funcionalidade ou característica específica de um sistema que atende a uma necessidade do usuário ou do negócio. Ao organizar o projeto em features, conseguimos dividir as tarefas em partes menores e mais gerenciáveis.

8. **Considerações Finais:** Reflexões sobre o processo de desenvolvimento, desafios enfrentados e aprendizados adquiridos.
